# Trae_skill

Trae 自定义 Skill 集合，用于增强 AI 助手的专项能力。

## 📦 Skill 列表

### 1. interview-prep — 面试准备方案生成器

根据用户提供的 **JD（岗位描述）** 和 **简历**，自动生成一份完整的、结构化的 HTML 面试准备方案。

#### 输入要求

- **JD**：目标岗位的完整描述文本
- **简历**：应聘者的完整简历文本
- **可选**：岗位方向、公司信息、个人补充说明

#### 使用方式

在 Trae 对话中，提供 JD 和简历后，可通过以下方式调用：

```
/skill:interview-prep [JD内容] [简历内容]
```

或直接在对话中说明：

```
帮我准备面试，JD 是...，我的简历是...
```

#### 输出内容

生成单文件 HTML，包含 8 大板块：

| 板块 | 内容 |
|------|------|
| 1. 自我介绍 | 1.5-2 分钟版本，重音关键词标注 |
| 2. JD 拆解 | 硬性/软性要求逐条匹配，标注已满足/需补位 |
| 3. 简历映射 | STAR 框架经历提炼，亮点与追问预判 |
| 4. 专业问答 | 通用必问 + 岗位定制 + 加分题，每题含得分点与话术 |
| 5. 思维经验 | 思维导图式场景拆解，通俗类比，跨领域迁移 |
| 6. 情景模拟 | 高频情景题 + 答题框架 + 参考话术 |
| 7. 反问环节 | 高质量反问问题 + 禁忌问题 |
| 8. 备忘单 | 今晚必做清单 + 关键词速记 + 话术骨架 + 应急策略 |

#### 样式特点

- 科技清新风格：浅色背景 + 科技蓝主色调 + 青色渐变
- 毛玻璃质感卡片、微渐变背景光晕
- 支持折叠/展开各板块
- 备忘单支持打印/导出
- 完整移动端适配

#### 示例

```
用户输入：
JD: 产品经理实习生，协助进行用户调研、竞品分析、需求文档撰写，参与产品迭代
简历: 某大学计算机专业大三学生，有校园App项目经验，熟悉Axure、Figma，了解产品设计流程

输出：生成 interview-prep-guide.html（含自我介绍、JD拆解、专业问答、情景模拟等8大板块）
```

> ⚠️ **隐私说明**：生成的 HTML 文件包含您的个人面试信息，请勿上传至公开仓库。已通过 `.gitignore` 排除。

#### 文件位置

```
.trae/skills/interview-prep/SKILL.md    # Skill 定义
interview-prep-guide.html                # 生成的面试方案示例
```

---

## 🛠️ 安装与使用

1. 克隆本仓库到本地
2. 将 `.trae/skills/` 目录放置在你的 Trae 项目根目录下
3. 重新打开对话窗口即可自动加载 Skill
4. 在对话中描述相关需求即可触发对应 Skill

## 📝 新增 Skill

在 `.trae/skills/` 目录下创建新的 Skill 文件夹，包含 `SKILL.md` 定义文件，格式参考现有 Skill。
